# AARRR Model

<aside>
💡

전체 비즈니스 흐름을 데이터 파이프라인처럼 표현한 지표.

</aside>

| 단계 | 개념 | 설명 |
| --- | --- | --- |
| Acquisition | 획득 | 고객이 우리 서비스를 어떻게 처음 알게 되었는가? (광고, 검색 등) |
| Activation | 활성화 | 사용자가 서비스의 핵심 가치를 처음 경험 했는가? |
| Retention | 유지 | 사용자가 서비스를 지속적으로 사용하는가? |
| Referral | 추천 | 사용자가 자발적으로 주변에 입소문을 내는가? |
| Revenue | 매출 | 사용자가 최종적으로 결제에 도달했는가? |
